# Conteúdo

Esta pasta reúne os materiais produzidos durante o desenvolvimento do Projeto Victor.

Seu objetivo é registrar e compartilhar o conhecimento adquirido por meio de diferentes formatos.

## Exemplos

- Vídeos
- Artigos
- Apresentações
- Roteiros
- Publicações

## Relacionamentos

Um Conteúdo pode documentar:

- Um Objetivo de Aprendizado.
- Um Projeto.
- Um Lab.
- Um Recurso estudado.

Um mesmo conteúdo pode abordar diferentes aspectos do processo de aprendizagem.
