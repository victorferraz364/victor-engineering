# Projetos

Esta pasta contém os projetos desenvolvidos como forma de aplicação prática dos conhecimentos adquiridos.

Os projetos representam cenários reais ou simulados onde diferentes competências podem ser exercitadas.

Um mesmo projeto pode contribuir para vários Objetivos de Aprendizado.

## Exemplos

- Ferraz Armazéns
- Sistema Hospitalar
- Portal Corporativo

## Relacionamentos

Um Projeto pode se relacionar com:

- Um ou mais Objetivos de Aprendizado.
- Diversos Labs.
- Diversos Conteúdos.
- Diversos Recursos.

Um projeto representa a aplicação prática dos conhecimentos desenvolvidos durante o processo de aprendizagem.
