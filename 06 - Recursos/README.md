# Recursos

Esta pasta reúne materiais utilizados como apoio ao desenvolvimento dos Objetivos de Aprendizado.

Os recursos não representam conhecimento produzido, mas sim fontes de consulta e referência utilizadas durante os estudos.

Os detalhes e anotações desses materiais são mantidos no Segundo Cérebro (Obsidian).

## Exemplos

- Livros
- Cursos
- Documentações Oficiais
- Artigos Técnicos
- Pesquisas
- Ferramentas

## Relacionamentos

Um Recurso pode ser utilizado por:

- Diversos Objetivos de Aprendizado.
- Diversos Projetos.
- Diversos Labs.

Os Recursos representam a base teórica utilizada durante o desenvolvimento do conhecimento.
