# Objetivos de Aprendizado

Esta pasta reúne todos os Objetivos de Aprendizado definidos para o Projeto Victor.

Cada objetivo representa uma necessidade de desenvolvimento e descreve o que será aprendido, por que esse aprendizado é importante e como ele será alcançado.

Um objetivo pode estar relacionado a diversos projetos, laboratórios, conteúdos e recursos de estudo.

## Exemplos

- Infraestrutura
- React
- Arquitetura de Software
- Cloud

## Relacionamentos

Um Objetivo de Aprendizado pode se relacionar com:

- Projetos desenvolvidos para atingir o objetivo.
- Labs utilizados durante a aprendizagem.
- Conteúdos produzidos.
- Recursos utilizados como base de estudo.

Um mesmo Projeto, Lab ou Conteúdo pode atender diversos Objetivos de Aprendizado.
