# Labs

Esta pasta contém laboratórios utilizados para experimentação, validação e prática de tecnologias específicas.

Os laboratórios possuem escopo reduzido e são utilizados para adquirir conhecimento antes de sua aplicação em projetos maiores.

Um laboratório pode apoiar diversos projetos e objetivos de aprendizado.

## Exemplos

- DNS
- Docker
- Active Directory
- VLAN
- Kubernetes

## Relacionamentos

Um Lab pode se relacionar com:

- Um ou mais Objetivos de Aprendizado.
- Um ou mais Projetos.
- Conteúdos produzidos durante sua execução.
- Recursos utilizados como referência.

Os Labs servem como ambientes de experimentação antes da aplicação dos conhecimentos em projetos maiores.
